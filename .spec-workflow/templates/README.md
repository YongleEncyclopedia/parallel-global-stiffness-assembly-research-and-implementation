# Spec Workflow 内置模板目录

## 用途

保存需求、设计、任务、技术和结构说明模板。

## 存放内容

- 直接文件：`design-template.md`、`product-template.md`、`requirements-template.md`、`structure-template.md`、`tasks-template.md`、`tech-template.md`
- 子目录：当前没有直接子目录。

## 不应存放

当前项目事实、一次性报告或结果数据。

## 维护提示

模板面向工具复用；中文说明可以补充，但占位符和字段语义不要随意改。

## 相关入口

- 上级目录：[.spec-workflow](../README.md)
