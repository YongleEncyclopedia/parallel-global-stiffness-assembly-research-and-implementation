# 实验与报告自动化脚本目录

## 用途

保存运行 benchmark、打包结果、绘图、验证和平台检查的 Python/MATLAB 脚本。

## 存放内容

- 直接文件：`archive_gpu_legacy.py`、`benchmark_figure_style.py`、`compare_validation_displacements.py`、`cross_platform_schema.py`、`cross_platform_schema_v2.py`、`generate_mesh.py`、`inspect_cpu_platform.py`、`package_cross_platform_results.py`、`package_cross_platform_results_v2.py`、`plot_core_profile_comparison.py` 等 28 个直接文件
- 子目录：当前没有直接子目录。

## 不应存放

C++ 库实现、原始大文件或手写报告正文。
