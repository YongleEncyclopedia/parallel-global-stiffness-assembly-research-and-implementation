# Linux 五类数值组装算法线程趋势图说明

## 图表目标

展示各算法随线程数变化的非线性扩展规律，并识别其最佳线程区间与性能瓶颈。

## 数据物理含义

- 每张图只展示一种并行数值后端在 1..20 线程下的趋势。
- 基线为 `symbolic_reuse_serial / cpu_serial / 1线程`。
- 并行行均为 `parallel_symbolic_reuse`，即并行符号组装 + 对应并行数值后端。
- `numeric_ms = backend_prepare_ms + assembly_numeric_ms`；图中仍统一显示为“数值组装”。
- `总耗时 = symbolic_total_ms + numeric_ms`；图中总耗时只拆成“符号组装 + 数值组装”两部分。
- 内存使用 `isolated_peak_rss_mb`，图中额外内存为相对串行基线峰值 RSS 的新增部分。

- 每个线程点来自 3 次独立进程测试的中位数，正确性检查均通过。
