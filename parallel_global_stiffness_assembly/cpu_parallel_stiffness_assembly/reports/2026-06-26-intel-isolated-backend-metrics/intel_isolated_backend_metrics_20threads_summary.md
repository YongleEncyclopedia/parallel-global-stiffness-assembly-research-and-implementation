# Intel 隔离进程数值组装后端图件说明

## 数据物理含义

- 本轮每个算法、线程数、重复次数都在独立子进程中测量。
- `isolated_peak_rss_mb` 是该子进程的峰值 RSS，可用于算法间内存对比。
- `符号预处理_ms = symbolic_ms_mean`，包含稀疏结构、写入位置表和后端准备。
- `数值组装_ms = numeric_ms_mean`，表示真正向全局矩阵 values 写入数值的耗时。
- `总耗时_ms = symbolic_numeric_total_ms_mean = 符号预处理 + 数值组装`。
- 整体加速比以串行 1 线程总耗时 4264.053 ms 为基线。

## 覆盖性检查

- 串行基线为 1 线程 PASS，2-20 线程为 SKIP 审计行。
- 其余后端均覆盖 1-20 线程 PASS 记录。
- 输入不含 direct assembly，也不含 `cpu_coo_sort_reduce`。
