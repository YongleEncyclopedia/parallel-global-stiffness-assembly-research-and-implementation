# CPU 主线小型输入样例目录

## 用途

保存 tiny/small Abaqus `.inp` 和 validation 子目录，供测试与验证使用。

## 存放内容

- 直接文件：`small_c3d4_gap_labels.inp`、`tiny_c3d4.inp`、`tiny_c3d4_with_output_sections.inp`
- 子目录：`validation/`

## 不应存放

真实大网格、benchmark 输出或源码实现。

## 维护提示

样例应尽量小而稳定，便于回归测试。
