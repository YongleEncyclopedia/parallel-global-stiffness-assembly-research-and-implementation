## Display Convention

Sparse-pattern figures use the standard matrix display convention: row index increases downward, column index increases to the right, and nonzeros are drawn as black marks on a white background.

## External Matrix Boundary

No Abaqus or MATLAB externally assembled correct matrix is included in this deck. Current numerical correctness uses the C++ `cpu_serial` assembled matrix as reference. MATLAB is used only for sparse-pattern visualization of exported row/column patterns.
