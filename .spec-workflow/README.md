# Spec Workflow 工具目录

## 用途

保存 spec-driven workflow 的模板和用户自定义模板。

## 存放内容

- 直接文件：当前没有直接文件，主要通过子目录承载内容。
- 子目录：`templates/`、`user-templates/`

## 不应存放

项目源码、实验结果或报告资产。

## 维护提示

模板字段可能被工具读取，翻译或改名时要避免破坏占位符。

## 相关入口

- 子目录：[`templates/`](templates/README.md)
- 子目录：[`user-templates/`](user-templates/README.md)
