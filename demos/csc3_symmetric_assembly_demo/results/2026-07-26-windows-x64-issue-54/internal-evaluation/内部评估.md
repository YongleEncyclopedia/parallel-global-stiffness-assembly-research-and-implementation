# CSC3 对称稀疏组装 Demo Windows 测试摘要

> 仅供内部评估

## 结论

**PASS。** Windows x64 下的双工具链构建、CTest、外部调用示例、全新目录复现、线程扫描和矩阵比较均已完成。

## 评估摘要

- MSVC + Ninja 和 MinGW-w64 + Ninja 均完成配置、编译、CTest 和外部调用验证；关闭或缺少 OpenMP 时，配置会失败。
- 同一源码 ZIP 分别在两个新目录中完成 MSVC 和 MinGW 构建，没有使用原仓库的构建缓存。
- WindHub 实验覆盖 $p=1,\ldots,16$，每档预热 $W=2$ 次、测量 $R=7$ 次，共 144 个独立进程样本。
- 最大相对 Frobenius 误差为 $1.510488\times10^{-16}$，满足 $10^{-8}$ 验收阈值。
- 最优总体加速比出现在 $p=16$，为 $2.1490$；并行总时间中位数为 $1428.320\ \mathrm{ms}$。$p=1$ 时并行路径慢于串行基线。
- 各线程档位的峰值工作集中位数约为 $4.797\ \mathrm{GiB}$，取自 Windows `GetProcessMemoryInfo().PeakWorkingSetSize`。

## 使用说明

- 结果只对应本次 Windows 主机、WindHub 输入及报告所列工具链。
- $8$ 线程以后仍有加速，但提升幅度已经减小，不能按理想线性加速外推。
- 性能数据对应提交 `14d89fad3b643b0ce81047aecbddd3e1cfb504e2`，源码 ZIP 对应提交 `419221b0ce58e37fca41fe48bbcbca9f71709ecf`；其间只修改了打包与追溯信息，没有改动算法、公共接口或 benchmark。
- 源码 ZIP 不含 WindHub 的 Git LFS 实体。复现实验时需另行取得与报告 SHA-256 一致的输入文件。
