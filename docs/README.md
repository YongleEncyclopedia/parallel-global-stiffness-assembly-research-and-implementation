# 仓库级文档目录

## 用途

保存项目范围、需求、平台协议和上下文边界。正在执行的开发计划不在本目录维护，而是以 GitHub Issues 为唯一状态源。

## 存放内容

- 直接文件：当前没有直接文件，主要通过子目录承载内容。
- 子目录：`context/`、`platform/`、`requirements/`

## 不应存放

可执行源码、构建产物、原始 benchmark 数据。

## 维护提示

给人阅读的新文档默认使用中文；代码标识、命令、路径和 schema key 可保留英文。Issue 关闭前，应把仍然长期有效的协议或决策迁入对应稳定文档；完成计划不在仓库中另建归档副本。

- 子目录：[`platform/`](platform/README.md)
- 子目录：[`requirements/`](requirements/README.md)
